---

## 📌 Features

- **Responsive Design**: Fluid layout that works seamlessly across desktops, tablets, and mobile devices.
- **Modern UI/UX**: Dark theme aesthetics with smooth hover states, clean typography, and interactive elements.
- **About & Skills**: Highlights core competencies in web development, database management (MySQL), and computer science fundamentals.
- **Activities & Extracurriculars**: Showcases university involvement and achievements.
- **Direct Contact Section**: Quick links to reach out via Email, Phone, and Socials.

---

## 🛠️ Tech Stack

- **HTML5** — Semantic page structure
- **CSS3** — Custom layout, animations, and responsive styling
- **JavaScript** — Interactive navigation and dynamic behavior
- **Font Awesome** — Vector icons
- **Vercel** — Automated CI/CD deployment & hosting

## 🚀 Local Development

To run this project locally on your machine:

1. Clone the repository:
   ```bash
   git clone git@github.com:Khadiza-X/Portfolio_Khadiza.git
   cd Portfolio_Khadiza
   ```

2. Open `index.html` in your favorite browser, or use a local dev server (like VS Code Live Server).
